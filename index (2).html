보내주신 7개 항목에 대해 공식 문서와 공개 고객 사례로 확인한 내용을 정리했습니다. 금요일에는 이 자료를 바탕으로 후속 교육의 범위와 일정을 정하면 됩니다(맨 아래 8번).

핵심 요약

질문 중 결론이 분명한 것부터 먼저 정리했습니다.

  • 에디션Standard에 채팅, Deep Research, Gemini Notebook(구 NotebookLM Enterprise), 사내 검색 커넥터, Data Insights, 이미지·영상 생성, 노코드 에이전트가 모두 들어 있습니다. Plus와의 차이는 사용자당 저장·색인 용량(30GiB vs 75GiB)과 일일 사용 한도입니다. 공식
  • Flow · 음원둘 다 Gemini Enterprise에는 없습니다. Flow는 Google Workspace의 추가 서비스이고, 음원 생성은 Workspace의 Google Vids 또는 Vertex AI의 Lyria API로 대체합니다. 공식
  • 크롤링 → 엑셀Gemini Enterprise 채팅이나 Deep Research만으로는 “채널의 모든 영상 제목”처럼 빠짐없는 목록을 보장하지 못합니다. Claude Code와 같은 방식(코드 작성 → 실행 → 엑셀)은 Standard 라이선스에 포함된 Antigravity로 할 수 있습니다. 공식
  • DatabricksGemini Enterprise에 Databricks 전용 커넥터는 없습니다. 커스텀 MCP 서버 연결이나 BigQuery 페더레이션으로 연계할 수 있지만 공개된 고객 사례가 없어 PoC로 검증해야 합니다. 공식
  • 동종 업계 사례엘리베이터 제조사(KONE, Otis, Schindler, TK Elevator)의 Gemini Enterprise 공개 사례는 찾지 못했습니다. 대신 제조(GE Appliances, Valeo, Bosch), 현장 서비스(Rentokil), 영업·제안(Beyond, KPMG) 사례를 정리했습니다. 사례
  • 확산의 공통점사내 검색으로 먼저 효과를 보여주고, 부서별 챔피언과 커뮤니티를 두고, 사용률 외에 절감 시간 같은 업무 지표를 함께 봅니다. 사례
  • 보안 검토한국 리전 데이터 보관은 아직 제공되지 않습니다(일본·싱가포르 등은 제공). Google 검색 그라운딩을 켜면 VPC-SC와 데이터 보관 위치 통제가 적용되지 않는 점도 정책에 반영해야 합니다. 공식
공식 Google 공식 문서 사례 공개 고객 사례 (수치는 모두 기업 발표 기준) 정리 메가존이 문서·사례를 바탕으로 정리한 방법론과 예시

1. 기능별 고객사 활용

기능마다 Standard 포함 여부와 주요 한도, 많이 쓰는 업무, 효과가 좋았던 용도와 기대에 못 미친 용도, 현업이 자주 하는 질문을 정리했습니다. 활용 내용은 공개 사례와 문서에 적힌 제약을 근거로 메가존이 정리했습니다.

일일 사용 한도는 공식 문서에 “기존(legacy) 할당” 기준으로 나와 있고, 2026-08-17부터 새 초과 사용 과금 방식이 적용되었습니다. 현대엘리베이터 계약 기준 수치는 Google에 따로 확인해야 합니다.

1-1Gemini 채팅 (모델 선택 · 파일 분석 · 메모리)

Standard 포함
모델은 관리자가 켜 둔 모델 중에서 고릅니다. 파일 업로드 한도: PDF·PPTX 100MB, XLSX 50MB, 이미지 30MB, MP4·MP3 200MB, CSV·TXT 7MB, DOCX 3MB. 파일 개수 제한 대신 대화와 파일을 합쳐 80만 토큰까지 처리합니다. 표는 Google Sheets로, 답변은 Docs로 내보낼 수 있고 Canvas에서 문서와 슬라이드를 만들어 DOCX·PPTX·PDF로 받을 수 있습니다. 일일 질문 160회(기존 할당). 모바일 앱(iOS·Android, 2026-06 정식 출시)에서도 음성 입력, 답변 읽어주기, 카메라 사진 첨부, 에이전트 실행을 쓸 수 있고, 웹 채팅창 음성 입력은 2026-09 정식 출시되었습니다(관리자 활성화). 공식

많이 쓰는 업무

  • 메일·보고서·공문 초안
  • 긴 문서 요약, 두 문서 비교
  • 엑셀·CSV 집계와 표 정리
  • 번역, 회의록 정리

효과가 좋았던 용도

  • 엑셀 분석: 실행한 코드가 함께 보여 결과를 검증할 수 있음
  • RFP와 표준계약서처럼 두 문서의 조건 충돌 찾기
  • Canvas로 보고서 초안을 만들고 PPTX로 받기

기대에 못 미친 용도

  • 3MB가 넘는 DOCX (PDF로 바꿔 올리면 100MB까지 가능)
  • 최신 정보를 근거 없이 물어보기
  • .xlsx 파일을 바로 내려받으려는 경우 (문서상 Sheets 내보내기만 확인됨)

자주 하는 질문과 오해

  • “메모리가 회사 지식을 학습한다” → 사용자 개인 대화·선호를 기억하는 기능입니다. 관리자가 전사적으로 끌 수 있습니다.
  • “입력한 내용이 모델 학습에 쓰인다” → 쓰이지 않습니다.
  • 메모리를 지워도 원래 대화가 남아 있으면 내용이 남을 수 있습니다.

1-2Deep Research

Standard 포함
사내 색인 데이터를 기본으로, 웹 검색이 켜져 있으면 웹까지 조사합니다. 조사 계획을 사용자가 수정한 뒤 실행하며 결과는 출처가 달린 보고서와 1~2분 오디오 요약으로 나옵니다. 일일 3회(기존 할당, Plus는 10회), 초과 시 회당 $4. 공식

많이 쓰는 업무

  • 시장·경쟁사 동향 조사
  • 기술·규제 변화 조사
  • 사내 자료와 외부 자료를 섞은 배경 보고서

효과가 좋았던 용도

  • 출처가 달린 초벌 보고서를 빠르게 만들기
  • KPMG는 출시 직후 사용량이 많은 기능으로 꼽음 사례

기대에 못 미친 용도

  • “모든 영상”, “모든 입찰 공고”처럼 빠짐없는 목록 수집
  • 정해진 칸에 맞춘 정형 데이터 추출
  • 하루 3회라 반복 업무에는 부족

자주 하는 질문과 오해

  • “특정 사이트를 전부 긁어 오는 크롤러인가” → 검색 기반 조사 도구입니다.
  • 결과의 수치와 인용은 원문 확인이 필요합니다.

1-3Gemini Notebook Enterprise (구 NotebookLM Enterprise)

Standard 포함
2026년 7월 이름이 바뀌었습니다. 사용자가 넣은 자료 안에서만 답합니다. 사용자당 노트북 500개, 노트북당 자료 300개, 자료당 500MB 또는 50만 단어, 하루 질문 500회. 오디오 개요·비디오 개요·마인드맵·리포트는 각각 하루 20회. YouTube와 웹 URL도 자료로 넣을 수 있으나 VPC-SC 환경에서는 웹 URL이 막힙니다. 공유는 같은 프로젝트 안에서만 됩니다. 오디오 개요는 한국어를 포함한 80개 이상 언어를 지원합니다(일반 도움말 기준). 공식

많이 쓰는 업무

  • 제품 매뉴얼·사내 규정 Q&A
  • 신규 입사자 교육자료
  • 법규·인증 기준 문서 학습
  • 프로젝트 자료 묶음 정리

효과가 좋았던 용도

  • 범위가 정해진 자료 묶음에 대한 근거 있는 답변
  • 오디오 개요로 이동 중 학습
  • KPMG: 약 6주 만에 노트북 약 11,000개 공유 사례
  • Freshfields: 실사 문서 대량 종합 사례

기대에 못 미친 용도

  • 자료에 없는 내용을 묻는 경우
  • 자주 바뀌는 문서 (자료를 직접 다시 올려야 함)
  • 도면·표가 많은 스캔 PDF

자주 하는 질문과 오해

  • “사내 검색과 무엇이 다른가” → Notebook은 넣은 자료만, 사내 검색은 연결된 시스템 전체를 봅니다. 사내 검색에서 찾은 문서를 노트북에 넣어 함께 쓰도록 설계되어 있습니다.
  • 오디오 개요의 대화형 모드는 영어만 됩니다.

1-4사내 문서 검색 (커넥터)

Standard 포함 · 전체 커넥터
연합(federated) 방식은 원본 시스템에 그때그때 질의하고, 수집(ingested) 방식은 내용을 색인으로 복사해 검색 품질이 더 좋습니다. Google Drive는 연합 방식이며 사용자 본인 권한으로 검색합니다. SharePoint, Confluence, Jira, ServiceNow, Salesforce 등 서드파티 커넥터와 커스텀 커넥터·MCP 연결을 지원합니다. 동기화 주기: 사용자·그룹 정보 최소 30분, 문서 전체·증분 최소 3시간. 공식

많이 쓰는 업무

  • 규정·양식·지침 찾기
  • 과거 제안서·견적서·계약서 찾기
  • 프로젝트 이력과 담당자 찾기

효과가 좋았던 용도

  • 여러 시스템에 흩어진 문서를 한 번에 찾기
  • KPMG는 “사내 검색부터 시작해 사용자를 확보하라”고 권고 사례

기대에 못 미친 용도

  • 구버전·중복·스캔 문서가 많은 저장소
  • 권한 정리가 안 된 저장소
  • SharePoint·OneDrive의 복잡한 PDF는 연합보다 수집 방식이 권장됨

자주 하는 질문과 오해

  • “검색되면 모두가 볼 수 있다” → 본인 권한 범위의 문서만 답변에 쓰입니다. 원본 권한이 과하게 열려 있으면 그대로 노출됩니다.
  • 권한 변경·삭제는 증분 동기화에 반영되지 않고 전체 동기화 때 반영되어 시차가 생깁니다.

1-5Data Insights 에이전트

Standard 포함 (Business 미포함)
자연어 질문을 SQL로 바꿔 실행하고 표·차트·요약으로 답합니다. 데이터 원본은 BigQuery만 지원합니다. 관리자가 OAuth 설정, 사용자 IAM 권한, 사용할 테이블 목록, 예시 질문과 SQL을 준비해야 합니다. 공식

많이 쓰는 업무

  • 수주·매출·AS 건수 같은 집계 조회
  • 현업의 단순 데이터 요청을 셀프서비스로 전환

효과가 좋았던 용도

  • 지표 정의가 정리된 집계 테이블
  • 컬럼 설명과 예시 SQL을 넣어 둔 경우
  • GE Appliances: 교대 데이터 분석이 몇 시간에서 몇 분으로 사례

기대에 못 미친 용도

  • 원천 테이블을 설명 없이 그대로 연결
  • 예측·상관·이상 탐지 질문 (Conversational Analytics 문서상 미지원)

자주 하는 질문과 오해

  • “엑셀을 올려서 쓰는 기능인가” → 엑셀 분석은 채팅에서 합니다.
  • “Databricks에 바로 붙는가” → 7번 Q&A 참고.

1-6Nano Banana / Nano Banana Pro (이미지 생성·편집)

Standard 포함 · 관리자 활성화
2026년 6월 앱에서 정식 출시되었고 기본값은 꺼짐입니다. Pro는 global 리전에서만 쓸 수 있습니다. 이미지를 올려 편집할 수 있고 결과는 PNG입니다. 일일 5장(기존 할당), 초과 시 장당 $0.02. 공식

많이 쓰는 업무

  • 보고서·교육자료 삽화
  • 사내 홍보물, 행사 포스터 시안
  • 제품 사진 배경 정리

효과가 좋았던 용도

  • 시안을 빠르게 여러 개 만들어 방향 정하기
  • 기존 사진의 부분 수정

기대에 못 미친 용도

  • 정확한 치수·도면이 필요한 이미지
  • 브랜드 가이드를 엄격히 지켜야 하는 최종 결과물
  • 이미지 안의 한글 문구 (2024년 보도에서 깨짐 지적, 최신 모델은 시연으로 확인 필요)

자주 하는 질문과 오해

  • “하루 몇 장까지 되나” → Standard는 기본 5장으로 적습니다.
  • 실제 사진처럼 보이는 이미지를 외부에 쓸 때는 AI 생성 표기 정책이 필요합니다.

1-7Veo (영상 생성)

Standard 포함 · 관리자 활성화
이미지·영상 생성 기능으로 포함됩니다. 일일 2회(기존 할당), 초과 시 영상 초당 $0.40. 문서에 모델 버전과 영상 길이가 적혀 있지 않아 실제 화면으로 확인해야 합니다. 공식

많이 쓰는 업무

  • 짧은 홍보 클립, 교육 영상에 넣을 장면

효과가 좋았던 용도

  • 촬영이 어려운 장면의 콘셉트 영상

기대에 못 미친 용도

  • 긴 영상, 자막·내레이션까지 붙인 완성본 (Google Vids나 Flow 영역)
  • 하루 2회라 반복 수정이 어려움

자주 하는 질문과 오해

  • “Flow와 같은 것인가” → Flow는 Veo로 장면을 이어 붙이는 별도 영상 제작 도구이며 Gemini Enterprise에 없습니다.

1-8Agent Designer (현재 Workflow Builder) · Agent Gallery

Standard 포함
Agent Designer는 Workflow Builder로 이름이 바뀌었고 2026-09-03 정식 출시되었습니다(에디션 비교표에는 아직 preview 표기). 채팅형 에이전트와 워크플로(트리거, 커넥터 동작, MCP, 사람 승인 단계, 예약 실행)를 코드 없이 만듭니다. Agent Gallery는 Google 제작, 우리 조직, 내 에이전트, 마켓플레이스(관리자 승인)로 나뉩니다. ADK로 개발한 에이전트도 등록할 수 있습니다(Standard는 사용자당 하루 1건 등록). 공식

많이 쓰는 업무

  • 정기 보고서 작성
  • 메일 분류와 회신 초안
  • 회의 후 후속 조치 정리
  • 부서 FAQ 응답

효과가 좋았던 용도

  • KPMG: 첫 몇 주에 노코드 에이전트 약 700개 사례
  • GE Appliances: 노코드와 커스텀을 합쳐 800개 이상 사례

기대에 못 미친 용도

왼쪽 단계에서 해결되면 멈추고, 안 될 때만 오른쪽으로 넘어갑니다. 정리

단계 1채팅내 파일과 일반 지식으로 해결자료가 손에 있나?
단계 2조사·정리Deep Research, Notebook외부 조사나 정해진 자료 묶음인가?
단계 3사내 검색커넥터, Data Insights자료가 사내 시스템에 흩어져 있나?

단계 5개발 이관ADK, Vertex AI, Antigravity시스템 연동·대량·실시간이 필요한가?

기능을 잘못 골랐을 때 생기는 차이 (예시)

상황잘못 고른 기능 → 결과맞는 기능 → 결과
사내 출장 규정 질문웹 검색 켠 채팅 → 일반적인 답사내 검색 → 우리 규정 조항과 출처
경쟁사 전체 제품 목록Deep Research → 일부 누락, 누락 여부도 모름API 스크립트 → 전체 목록
매달 바뀌는 단가표 Q&ANotebook → 지난달 자료로 답사내 검색(자동 동기화) → 최신 자료
한 번만 할 경쟁 입찰 분석에이전트 제작 → 만드는 시간이 더 듦채팅 → 바로 결과

정보보안 관점 판단

플랫폼이 보장하는 것 공식

  • 입력과 결과는 Google 모델 학습에 쓰이지 않음
  • 채팅 보관 기간 1~180일 설정 (기본 60일)
  • Model Armor로 프롬프트·응답 검사, 개인정보 차단 (추가 비용 없음)

주의할 예외 공식

  • Google 검색 그라운딩을 켜면 VPC-SC·데이터 보관 위치 통제가 적용되지 않음. 대신 Enterprise web search 사용
  • Model Armor는 ADK·A2A 에이전트에는 적용되지 않음
  • 한국 리전 없음. CMEK는 US·EU 멀티 리전만

넣으면 안 되는 데이터 정리

  • 비밀번호, API 키 등 인증 정보
  • 주민등록번호 등 고유식별정보
  • 비밀유지 계약이 걸린 고객 원문 (계약 조건 확인)
  • 수출 통제 대상 기술 자료
  • 미공개 재무·인사 정보 (사내 정책에 따름)

Google 문서에 금지 목록은 따로 없으므로 사내 보안 정책으로 정해야 합니다.

커넥터 권한과 답변 범위 공식

  • 답변은 질문한 사람의 원본 권한 범위 안에서만 만들어짐
  • 권한 변경은 전체 동기화 때 반영되어 시차가 있음
  • 연합 검색은 질문 문장이 외부 시스템으로 전달되고 그 시스템의 약관이 적용됨
  • 도입 전에 “전체 공개”로 열린 폴더부터 정리

7. Q&A 및 기타

바이브코딩 배포 용도로 쓰는 사례가 있나요?

도구내용상태
AntigravityStandard·Plus 라이선스에 포함. 샌드박스, 브라우저·MCP 접근 정책, 감사 로그, 예산 한도 같은 관리 기능 제공권장
Google AI Studio BuildReact/Node 앱을 만들어 Cloud Run에 바로 배포. Gemini API 약관이 적용되고 앱 소유자가 책임을 지므로 기업은 회사 GCP 프로젝트로 써야 함통제 필요
Gemini Enterprise Canvas문서·슬라이드 전용. 앱 제작 기능은 없음앱 제작 불가
Firebase Studio · Gemini Code AssistFirebase Studio는 2027-03-22 종료 예정, Code Assist는 2026-10-09부터 신규 구독 중단. Antigravity로 안내신규 도입 비권장

공개 사례로는 AirAsia(재무·마케팅·법무·HR로 Antigravity 확대 중)와 Datamatics(여러 앱 개발·배포)가 있지만 성과 수치는 없습니다. 비개발자가 만든 사내 도구를 배포할 때는 배포 위치(회사 GCP 프로젝트), 인증, 데이터 접근 범위, 운영 책임자를 먼저 정하는 것이 좋습니다. 정리

타사 AI-Ready Data 준비 사례

문서 데이터 공식

레이아웃 파서 권장, 스캔 PDF는 OCR 파서(앞 500쪽까지). 문서 조각은 100~500토큰이며 상위 제목을 함께 넣을 수 있음. 조각 설정은 데이터 저장소를 만든 뒤 바꿀 수 없음. 파일당 200MB 미만.

정형 데이터 공식

BigQuery 테이블에 테이블·컬럼 설명, 동의어, 예시 질문과 SQL, 업무 용어집, 조인 관계를 넣어 둠. 자주 쓰는 컬럼부터 설명.

권한 데이터 공식

커스텀 커넥터는 문서별 ACL을 함께 넣어야 함. 이메일이 아닌 사용자 ID는 매핑 필요. 중첩 그룹은 펼쳐서 등록.

공개 사례 사례

KPMG: 데이터 품질을 성공의 핵심으로 꼽고 커넥터가 맞는 권한으로 맞는 데이터를 돌려주는지 평가. Virgin Media: Knowledge Catalog로 숨어 있던 데이터 자산 2만 개 이상 활용.

Databricks 등 기존 데이터 플랫폼과의 연계

방식구조상태
A. MCP 연결Databricks 관리형 MCP 서버(Genie, Vector Search, DBSQL 등, 공개 프리뷰) → Gemini Enterprise 커스텀 MCP 서버로 등록. 스트리밍 HTTP, OAuth, 도구 100개까지공식 공동 가이드 없음 · PoC
B. BigQuery 페더레이션BigQuery가 Unity Catalog 테이블을 Iceberg로 읽음(프리뷰) → Data Insights·Conversational Analytics에서 사용외부 테이블 제약 확인 필요
C. Databricks 안에서 Gemini 사용2025-06 파트너십. SQL ai_query, Agent Bricks에서 Gemini 모델 호출. 데이터는 Databricks에 그대로사용 가능
D. 서드파티 브리지CData 등 상용 커넥터별도 구매

Databricks를 유지하면서 Gemini Enterprise와 연계한 공개 고객 사례는 찾지 못했습니다. 현대엘리베이터 Databricks 환경(클라우드, Unity Catalog 사용 여부)을 확인한 뒤 A 또는 B로 소규모 PoC를 권합니다. 정리

AX 과제 도출 워크숍

요구 파악 질문과 입력→처리→출력 분해로 부서별 과제를 뽑고, 기능 선택 흐름에 맞춰 우선순위를 정합니다. 2·5·6번 항목 대응.

기술·거버넌스 세션
